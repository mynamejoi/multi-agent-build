# Contracts

The seams between the agents. Each file has one owner, the only agent that edits it.

They start as v0 sketches written by the planning conversation. Each owner makes v1 first thing.

To change a contract you don't own, write a request in your status file and send the owner a heads-up. When you change your own: bump the version line, note it in your status file, tell the agents who use it, and keep the old shape working until they've moved.
